# 🌍 Travelgram

Uma interface moderna inspirada em uma rede social de viagens, desenvolvida com foco na prática de **HTML5** e **CSS3**, explorando conceitos de estruturação semântica, layout responsivo e boas práticas de desenvolvimento Front-end.

## 📖 Sobre o projeto

O **Travelgram** é um projeto criado para aprimorar conhecimentos em desenvolvimento web, reproduzindo uma interface elegante e intuitiva voltada ao compartilhamento de experiências de viagem.

Durante o desenvolvimento foram aplicados conceitos essenciais de HTML e CSS, priorizando organização do código, responsividade e uma boa experiência visual.

## ✨ Funcionalidades

* Interface moderna e responsiva;
* Layout organizado utilizando Flexbox;
* Estrutura HTML semântica;
* Componentes reutilizáveis;
* Design inspirado em redes sociais de compartilhamento de fotos.

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3


## 📱 Responsividade

O projeto foi desenvolvido para oferecer uma boa experiência em diferentes tamanhos de tela, adaptando os elementos da interface para dispositivos móveis e desktops.

## 🎯 Objetivos de aprendizado

Este projeto foi desenvolvido com o objetivo de praticar:

* Estruturação semântica em HTML;
* Organização de arquivos;
* Estilização com CSS;
* Layout utilizando Flexbox;
* Responsividade;
* Boas práticas de desenvolvimento Front-end.
